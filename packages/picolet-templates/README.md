# picolet-templates

Starting templates used by `picolet init <name>`.

Planned:

- `hello-webview/` — minimal app with the webview renderer
- `hello-lvgl/` — minimal app with the LVGL renderer
- `hello-cli/` — minimal headless app (CLI tool pattern, à la pydfu)

Each template is a directory tree mirroring the user-app layout from
[docs/architecture.md](../../docs/architecture.md#app-level-picolettoml-schema)
with placeholder content.
